# Milestones — which commits are the ones that mattered

207 commits and counting. Most are increments; a few are points where the project became
something it was not before. This file names those, so a commit hash can be found from a
milestone and a milestone from a hash.

**Inclusion rule, kept narrow on purpose:** an entry earns its place only if it *changed what is
true about the project* — a capability that did not exist, a claim that became defensible or
stopped being, a direction that shifted. A good commit is not a milestone. If everything is
listed, nothing is findable, which is the failure this file exists to avoid.

**Not a changelog and not a decision log.** `CONSTRUCTION.md` holds open and closed decisions;
`INTEGRATION-DELTA.md` holds every change we made to someone else's code; this holds the handful
of moments worth navigating to.

## Two shifts of direction, recorded because they are easy to lose

**Port → clone.** The project began as `rlgen/`, a single shared trainer, evaluator and logger
for all twelve. That was superseded by twelve hermetic clones each running its authors' own
`train.py`, with the null being non-integration and any join carrying a burden of proof. The port
is not deleted and its era's reasoning is in `DECISION_LOG.md`; `docs/STATE-2026-08-16.md`
records what it contained.

**Instrument before result.** No training result exists, deliberately. The project's own status
doc puts it best: *"we could have produced a full twelve-row table a week ago, and several of its
rows would have been meaningless."* The audit is what stands between a table and a *true* table.
