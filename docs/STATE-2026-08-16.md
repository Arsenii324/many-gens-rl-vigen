but it is a result about **four files**, and it was obtained by reading four diffs, which is the
only thing that makes a percentage mean anything.

Descent is **provenance, not correctness**. `ctrl` reads 0% legitimately (JAX reference); `alda`
reads ~100% against a *sibling project's port* and 0% against the authors' repo. A high number can
mean copied-from-the-wrong-thing; a low one can mean faithfully reimplemented in another shape.
Always read the matched source.

## What T1 verifies, and the half of the network it structurally cannot reach

A weight transplant copies a reference `state_dict` into ours and requires identical forward
output. **It works precisely because an encoder is action-agnostic** — a conv stack over pixels
does not know whether the action space is discrete — so the continuous/discrete distinction never
reaches the part T1 checks.

| baseline | T1 covers | T1 cannot cover |
|---|---|---|
| `ppg` | `ImpalaCNN`: conv stacks + `dense`, at 64x64x3 and 84x84x9 | policy head, both value heads, PPO and auxiliary phases |
| `idaac` | `ResNetBase`, `ValueResNet`, and `PolicyResNetBase`'s **trunk only** | `critic_linear`, excluded explicitly: input width is `hidden + act_dim` here vs `hidden + num_actions` there |
| `ctrl` | `Impala` encoder against the Flax original | everything else |

**No transplant is possible for any action-conditioned path, by construction** — the references
ship no continuous head to transplant *from*. That is the same fact that makes those heads
authored. So the observation pathway has real numerical verification on three baselines; **the
action pathway has none anywhere in this project.**

## Continuous adaptations — the authored surface that cannot be verified against anything

Three references ship **no continuous policy head at all**, confirmed by reading each:

| Baseline | Evidence | Consequence |
|---|---|---|
| `ppg` | `distr_builder.py` routes Bernoulli/Categorical and **raises** otherwise; `_make_normal` has **no caller** and hardcodes `scale=1.0` with the authors' own `warnings.warn("Using stdev=1")` | head authored, NOT INTRINSIC |
| `idaac` | `distributions.py` defines only `FixedCategorical`/`Categorical`; `model.py:313,360` wires it unconditionally | head authored; worse, its `[IK]` citation names a repo **not on this disk** |
| `ibac_sni` | reaches its head via `make_pdtype`, whose Box branch was read from `openai/baselines` **over the network**, not from disk | head authored, one step weakened |

Project-wide continuous choices, applied **uniformly** so an error lands as a systematic offset
rather than selectively (`STEP-ZERO.md` gate 3): `init_log_std = -1.0` (baselines' own default is
0.0), `entropy_coef = 0.0` (every reference's is 0.01). The second has a consequence nobody chose:
**it makes IBAC-SNI's entropy-mixing inert**, so half of SNI does not run.

## Removals — what was cut and whether it was declared

- **Declared and defensible**: launcher/logging/env layers from every vendored base (`train.py`,
  `logger.py`, env wrappers) — replaced by the harness, recorded in each `PROVENANCE.md`.
- **Undeclared, found today**: `idaac`'s `NNBase` (inlined) and `LinearOrderClassifier`/
  `NonlinearOrderClassifier` (**hand-rewritten as `OrderDiscriminator` from a docstring that
  described them**, while the reference sat ten lines away in an already-vendored file). Both now
  copied verbatim; `STEP-ZERO.md` gate 1 extended to *copy the file, then justify each removal*.
- **Undeclared, still open**: `ppg` hardcodes `pi_enc`/`vf_enc` instead of carrying
  `PhasicValueModel`'s `vf_keys`/`get_encoder` machinery. Behaviour identical at `arch="dual"`.
